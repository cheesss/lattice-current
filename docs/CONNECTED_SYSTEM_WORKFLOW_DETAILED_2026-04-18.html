Connected System Workflow, Detailed

이 버전은 요약판이 아니라 상세판이다. 각 박스 안에 역할 설명을 한글로 넣었고, 수집, 저장, 계산, 서빙, 클릭, 인간 승인, OpenClaw 후속조치까지 하나의 흐름으로 묶었다. 마우스 휠로 확대/축소할 수 있고, 마우스로 드래그해서 이동할 수 있다.

조작법
마우스 휠로 확대/축소하고, 빈 공간을 드래그해서 이동할 수 있다. `원래 크기`는 100%로 되돌리고, `화면 맞춤`은 현재 뷰포트에 맞는 배율과 위치를 다시 계산한다.
구조 해석
이 다이어그램은 코드 파일 단위보다 시스템 역할 단위로 묶었다. 상세 파일명은 각 박스에 직접 쓰지 않고, 기능 계층과 흐름을 먼저 읽게 설계했다.
운영 의미
현재 실운영 중심 task는 `composite nowcasts`, `event-intensity nowcast`, `reconcile-nowcasts`다. `rates nowcast`는 opt-in이며 기본 흐름에서는 꺼져 있다.
