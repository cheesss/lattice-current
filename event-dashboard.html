Analytics
Event Decision Engine Visualizations
Counterfactual alpha, evidence grading, regime analysis, and model calibration.
Evidence Grade Distribution --
Classifies all event-asset pairs by statistical strength. E0 = noise (no excess return vs market). E1 = positive alpha. E2 = statistically significant uplift vs matched control days (t > 1.96). More E2 = more genuine signals.
Alpha Decay by Theme Horizon
Shows how excess return (alpha) diminishes over time for each news theme. Short bars that shrink = fast-fading signal. Bars that persist = durable edge. Measured at 1-week, 2-week, and 1-month horizons.
Event Intensity Heatmap 6mo
Hawkes process intensity by theme and month. Bright/red = cascading event cluster (news feeding more news). Dark = quiet period. Identifies when a theme is in "surge mode" with self-exciting event chains.
Signal Correlation 90d
90-day rolling correlation between market signals. Green = move together. Red = move opposite. High correlation means less diversification benefit. Key pairs: VIX vs credit spreads, oil vs dollar.
Regime Timeline VIX
Historical market regime based on VIX levels. Red = crisis (VIX > 25 + credit stress). Orange = risk-off. Blue = balanced. Green = risk-on (VIX < 18). Shows when defensive vs aggressive positioning was appropriate.
Conviction vs Realized Alpha Calibration
Scatter plot of model conviction score (x-axis) vs actual realized excess return (y-axis). Points near the diagonal = well-calibrated model. Cluster above = model is conservative. Below = model overestimates.
Source Credibility --
Trust score per news source based on how well their articles predict actual asset reactions. High score = articles from this source align with real price moves. Low score = noisy or unreliable source.
